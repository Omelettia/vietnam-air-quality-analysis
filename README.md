# Vietnam Air Quality Analysis

**Status:** Active (November 2025 - Present)

---

## Overview
This project integrates multi-source environmental data to evaluate air quality dynamics in Vietnam.

* **Objective:** Cross-validate ground sensor data against satellite imagery to assess regional pollution patterns.
* **Data Pipeline:** Built automated crawlers to scrape, clean, and synchronize data from **Envisoft** (Government), **IQAir** (Commercial), and **Himawari-8** satellites.
* **Analysis:** Applied **RANSAC Regression** to filter sensor outliers and model the correlation between Satellite AOD and Ground AQI.
